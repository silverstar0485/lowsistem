# 부산광역시의회 입법정책 지원 [타시도 조례 모니터링 & 신규 조례 발굴 시스템]

> 부산시의회 정책지원관이 전국 17개 광역 시·도의 최근 1년간 제·개정 조례 현황을 상시 모니터링하고, **부산시 미제정 조례 발굴 및 입법 Gap 분석**을 수행할 수 있도록 지원하는 풀스택 웹 애플리케이션 및 자동 수집 파이프라인입니다.

---

## 1. 주요 기능 (Core Features)

### (1) 데이터 수집 및 일일 자동 업데이트 (Data Collector & Scheduler)
- **전국 17개 광역 시·도 조례 수집**: 서울, 경기, 인천, 대구, 대전, 광주, 울산, 세종, 강원, 충북, 충남, 전북, 전남, 경북, 경남, 제주 최근 1년 내 제·개정 조례.
- **국가법령정보센터 자치법규 Open API 연동**: `APScheduler` 기반 매일 08:00 AM 정기 동기화 실행.
- **오프라인 100+ Mock Seeder**: API 키가 없어도 100건 이상의 최신 고품질 모의 데이터를 바탕으로 즉시 시스템을 시연·테스트 가능.

### (2) 부산시 조례 대조 & 입법 Gap 분석 (핵심 기능)
- **부산시 미제정/발굴 추천 태그**: 타 지자체에서 최근 '제정'된 조례 중 부산시에 유사/동일 조례가 없는 항목을 하이라이트 표시 (`부산시 미제정/발굴 추천`).
- **3줄 입법 시사점 요약**: 제정 배경, 주요 조항, 부산시 도입 시사점을 수집 시 자동 분석 및 제공.

### (3) 멀티 필터링 & 검색 대시보드
- **16개 광역 시·도 멀티 셀렉트**.
- **제·개정 구분 필터** (제정, 일부개정, 전부개정, 폐지).
- **공포 기간 필터** (최근 1개월, 3개월, 6개월, 1년, 전체).
- **부산시 미제정/발굴 추천 전용 원클릭 토글**.
- **추천 정책 키워드 Quick Chips** (#생성형 AI, #청년, #인구감소, #해양, #소상공인, #자율주행, #전기차 안전 등).
- **카드 뷰 & 고밀도 테이블 뷰** 상호 전환 지원.

### (4) 엑셀(.xlsx) 원클릭 보고서 내보내기
- SheetJS (`xlsx`) 탑재.
- 필터링 및 검색된 목록을 클릭 한 번으로 `.xlsx` 파일로 다운로드.
- 컬럼 구성: `[연번] | [시도명] | [조례명] | [제개정구분] | [공포일자] | [공포번호] | [소관부서] | [주요내용 요약] | [부산시 유무] | [부산시 대조결과] | [입법 시사점] | [검토상태] | [정책지원관 메모] | [원문URL]`

### (5) 정책지원관 개인 워크스페이스
- 관심 조례 북마크/스크랩 기능.
- 조례별 검토 의견/메모 작성 및 검토 상태 (`검토예정`, `검토중`, `발굴완료`, `보류`) 관리.

---

## 2. 기술 스택 (Tech Stack)

- **Frontend**: Next.js 14 (App Router), TypeScript, Tailwind CSS, Lucide React, SheetJS (`xlsx`)
- **Backend / API**: FastAPI (Python 3.12), SQLite3, APScheduler, Requests, Pydantic
- **Database**: SQLite (`backend/data/ordinance.db`)

---

## 3. 원클릭 구동 방법 (Quick Start Guide)

### Windows 로컬 환경 실행
프로젝트 루트 디렉토리에서 `start.bat` 실행:

```cmd
start.bat
```

> **구동 순서**:
> 1. 백엔드 파이썬 패키지 설치 및 SQLite DB 초기화 & 115건 시드 생성
> 2. FastAPI 백엔드 서버 구동 (`http://localhost:8000`)
> 3. Next.js 프론트엔드 웹 앱 구동 (`http://localhost:3000`)
> 4. 웹 브라우저 자동 연결

---

## 4. 수동 설치 및 실행 명령어

### 백엔드 (FastAPI)
```bash
cd backend
python -m pip install -r requirements.txt
python app/seeder.py
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

### 프론트엔드 (Next.js)
```bash
cd frontend
npm install
npm run dev
```
웹 접속: `http://localhost:3000`
